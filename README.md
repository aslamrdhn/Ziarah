# Ziarah Nusantara

Platform direktori dan peta interaktif untuk makam para wali, habaib, dan ulama di Indonesia.

## Fitur Utama

- **Peta Interaktif (Routing)**: Menampilkan titik lokasi makam dengan detail.
- **Progressive Web App (PWA)**: Dapat diinstal dan digunakan secara offline.
- **Kumpulan Doa & Panduan**: Panduan adab, doa tawasul, tahlil, dan yasin untuk berziarah.
- **Paywall Untold Story**: Simulasi fitur eksklusif untuk kontributor.

## Pengembangan

Aplikasi ini menggunakan React + Vite + TypeScript.

\`\`\`bash
npm install
npm run dev
\`\`\`
